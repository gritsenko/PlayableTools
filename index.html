Playable Ads Tools

This app provides a collection of open-source, useful tools for HTML5 playable ads developers.

Core Features:

  • Publish to Ad Networks: Streamline the process of deploying your playable ads to various advertising networks.
  • Assets Compression: Optimize your images, scripts, and other assets to reduce file size and improve loading times.
  • Base64 Converter: Convert files and images to Base64 encoding for embedding in your HTML5 playable ads.
  • Video to Sprite Converter: Transform MP4 videos into PNG sprite sequences for game development and animations.
  • Folder Size Visualizer: Analyze and visualize the size structure of local folders using interactive charts.
  • Imba Packer: Experimental HTML compression tool for maximizing file size reduction while preserving functionality.
  • CTA SDK Documentation: Complete guide for integrating the Call-to-Action SDK in your playable ads.
  • Ad Network Requirements: Stay up-to-date with the specific requirements and specifications for different ad networks.
  • Playable Ads Preview: Preview and share your playable ad creations from GitHub on different devices and orientations.
  • Portfolio Management: Manage and view your portfolio of playable ads from GitHub repositories.
